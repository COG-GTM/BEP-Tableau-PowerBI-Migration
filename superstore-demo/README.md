# Superstore demo: Tableau → Power BI, raw data → dashboard, Devin as analyst

One dataset, three stories. Everything here was generated by Devin from the Tableau workbook
`course/tableau-files/Section 15 - Tableau Sales & Customer Dashboards.twbx` (Sample Superstore,
9,994 orders, 2020–2023) and is reproducible with `./run_demo.sh`.

| Part | Input | What Devin built | Where |
|---|---|---|---|
| 1. Tableau → BI | the `.twbx` (15 sheets, 2 dashboards, 32 calculated fields, 1 parameter) | workbook inventory, Tableau-calc → DAX translation, a Power BI project (`.pbip`, TMDL model, PBIR report), the same two dashboards rebuilt live in Metabase, and a number check | `part1-tableau-to-powerbi/` |
| 2. Data → BI | the raw `orders` table in Postgres, no dashboard | SQL views (monthly sales, margin by category, top customers) and an executive dashboard with a Region filter | `part2-data-to-dashboard/` |
| 3. Devin as analyst | the same Postgres database | answers to three business questions with the SQL and a chart for each | `part3-data-analyst/` |

## Part 1 — Tableau to Power BI (and a live-rendered copy)

1. **Inventory** — `scripts/extract_twbx.py` opens the workbook, exports the embedded Hyper extract to
   `data/*.csv` and writes `inventory.md` / `inventory.json`: every data source, calculated field
   (with its Tableau formula), parameter, worksheet (with its shelves) and dashboard.
2. **Translation** — `scripts/build_pbip.py` turns the 32 Tableau calculations into DAX measures
   (`dax_translations.md`, side by side with the Tableau formula and a note on the translation),
   including the `Select Year` parameter (disconnected table + `SELECTEDVALUE`), the `COUNTD` →
   `DISTINCTCOUNT`, `INDEX()` → `RANKX`, LOD `{FIXED Customer ID : COUNTD(Order ID)}` → `SUMMARIZE`
   and the `WINDOW_AVG/MAX/MIN` table calcs.
3. **Power BI project** — `Superstore.pbip` with `Superstore.SemanticModel/` (TMDL: 7 tables,
   relationships, 32 measures) and `Superstore.Report/` (PBIR: 2 pages, 19 visuals mirroring the two
   Tableau dashboards). `sheet_mapping.md` lists every Tableau sheet and the visual it became.
4. **Validation** — `scripts/validate_pbip.py` checks the project statically (every measure/column a
   visual references exists, every DAX reference resolves, JSON schemas declared): see
   `validation_report.md`. **What this does not prove:** that DAX evaluates and visuals render — that
   needs Power BI Desktop or a Fabric workspace, neither of which runs on Linux. Open
   `Superstore.pbip` in Desktop to complete that step.
5. **Live copy** — the same two dashboards are also built in Metabase (one card per Tableau sheet, a
   `Select Year` filter standing in for the parameter) so the migration can be *seen* running:
   `scripts/metabase_setup.py`.
6. **Number check** — `scripts/number_check.py` asks Tableau's own Hyper engine, Postgres and a
   pandas replica of the DAX the same questions (KPIs and sales by sub-category for the selected
   year). All match to the cent: `number_check.md`.

## Part 2 — Raw table to executive dashboard

`part2-data-to-dashboard/01_schema.sql` loads the four raw tables as-is (the source has duplicate
Product IDs and a null Postal Code, so those are kept non-unique rather than "fixed").
`02_views.sql` adds the `analytics` schema: `order_lines`, `monthly_sales`, `margin_by_category`,
`top_customers`, `region_scorecard`. `scripts/metabase_setup.py` builds **Superstore — Executive
Sales Dashboard** on top of them with a Region filter.

## Part 3 — Devin as data analyst

`part3-data-analyst/answers.md` answers, with SQL (`questions.sql`) and a chart each:

1. Top 10 customers by profit last year (lookup).
2. Monthly sales by region (trend + chart).
3. Why did profit drop in the Central region in Q4 2023? (why): Binders sold at 47% average discount
   flipped from +$5.6k to −$4.4k, and the Q4 2022 baseline held a one-off $8.4k Copiers sale.

These were produced by Devin in-session against Postgres. The Slack `/dana` Data Analyst flow needs
an MCP data source wired to the agent; see the PR description for the status in this environment.

## Run it

```bash
cd superstore-demo
./run_demo.sh            # Docker (Postgres + Metabase), Python 3.10+
# Metabase: http://localhost:3000  (login printed by scripts/metabase_setup.py; demo-only credentials)
```
